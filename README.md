# Sales Performance Dashboard

## Overview
This project is an interactive Power BI dashboard analyzing sales performance across regions, categories, and customer segments.

## Features
- KPI Cards
- Monthly Sales Trend Analysis
- Sales by Region
- Sales by Category
- Interactive Slicers
- Top Products Analysis

## Tools Used
- Power BI
- Power Query
- DAX

## Files Included
- Power BI Dashboard (.pbix)
- Dataset (.csv)
- Dashboard Screenshots
